03 / Case study · Enterprise Operations

From scattered notes to engineering-ready tickets, with AI

How AI-built skills and an AI-built workflow application let one product manager turn unstructured notes into consistent requirements, service maps, and tickets, cutting artifact time by about 63%.

Capability
Enterprise Operations
Focus
AI-powered workflow automation
Scope
Hands-on build, end to end
Result
~63% less time on artifacts

The pattern

Product managers spend a large share of their time creating and maintaining artifacts: requirements, service maps, and tickets. Each one lives in a different place, so every change has to be repeated by hand.

Over time the documents drift out of sync, and engineers end up building from versions that no longer agree.

My approach

  • Turned PM know-how into reusable AI skills. Using AI coding tools, I created skills that produce product management artifacts in a consistent structure.
  • Built the workflow with AI, too. I used the same AI coding tools to build a browser-based workflow application that brings those skills together in one place.
  • One product manager, notes to tickets. The workflow takes unstructured notes and documentation all the way to structured requirements, service maps, and tickets for downstream engineers.
  • Change once, update everywhere. Any change to requirements is applied consistently across every artifact, eliminating drift.

Impact

  • About 63% less time spent creating and managing artifacts.
  • No drift between requirements, service maps, and tickets.
  • A single product manager able to run the full pipeline from notes to engineering-ready work.
